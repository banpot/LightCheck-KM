# ความเชื่อมโยงกับ Green Office ปี 2569 ข้อ 5.2.1

เรื่องแสงในสำนักงานอยู่ใน **หมวด 5 สภาพแวดล้อมและความปลอดภัย ข้อ 5.2** (ไม่ใช่หมวด 6) [1]

| ข้อกำหนด 5.2.1 | สิ่งที่ LightCheck KM รองรับ | หลักฐานที่ควรแนบ |
|---|---|---|
| (1) ตรวจวัดประจำปี ทั้งจุดทำงานและพื้นที่ทำงาน | SOP + `grid_planner.py` แยกจุด area / workstation | รายงานผล + ผังจุดวัด |
| (2) เครื่องวัดได้มาตรฐานและได้รับการสอบเทียบ | ผลทางการใช้ calibrated reference meter; เครื่องต้นแบบเป็น pre-survey | ใบรับรอง calibration ของเครื่องมาตรฐาน |
| (3) ผลเป็นไปตามกฎหมาย | เกณฑ์ 300/150 lux (พื้นที่) และ 400–500 lux (จุดทำงาน) | ตารางเปรียบเทียบกับเกณฑ์ |
| (4) ผู้ตรวจใช้เครื่องมือถูกต้อง | คู่มือ + SOP + การสาธิต วิธีวางหัวรับแสงและกันเงา | รายชื่อผู้ผ่านการถ่ายทอด / ภาพสาธิต |
| (5) มีภาพประกอบ | กำหนดให้ถ่ายภาพเป็นขั้นตอนหนึ่งของ SOP | ภาพจุดทำงานและพื้นที่ทำงาน |
| กรณีผลไม่ผ่าน | บันทึก corrective action และตรวจซ้ำ ได้คะแนนเต็มเมื่อแก้ไขแล้วผ่าน [1] | Before/After + ผลตรวจซ้ำ |

ข้อห้าม: **ห้ามใช้แอปบนโทรศัพท์มือถือเป็นหลักฐานการตรวจวัด** [1]
เครื่องต้นแบบนี้จึงใช้คัดกรองและจัดลำดับความเร่งด่วน ไม่ใช้แทนหลักฐานทางการ
