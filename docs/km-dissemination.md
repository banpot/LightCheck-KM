# การถ่ายทอดและเผยแพร่องค์ความรู้ภายในมหาวิทยาลัย

องค์ความรู้ทั้งชุดเปิดเป็น **Public repository** เพื่อให้บุคลากรทุกส่วนงานของมหาวิทยาลัยศิลปากร
เข้าถึง ทำซ้ำ และต่อยอดได้เอง โดยไม่ต้องขอสิทธิ์ และไม่ผูกความรู้ไว้กับบุคคลเดียว

## ช่องทางการเผยแพร่

| ช่องทาง | สิ่งที่ผู้รับได้ | สถานะ |
|---|---|---|
| GitHub repository (public) | Source code, ไฟล์ STL กล่อง, ผังวงจร, คู่มือ, SOP, แบบบันทึก, เครื่องมือคำนวณ | เผยแพร่แล้ว |
| GitHub Issues | ช่องถาม-ตอบและแจ้งปัญหา คำตอบสะสมเป็นความรู้ให้ผู้ถามคนถัดไป | เปิดใช้แล้ว |
| [`docs/open-problems.md`](open-problems.md) | หัวข้อที่เปิดให้ร่วมพัฒนาต่อ พร้อมทักษะที่ใช้และระดับความยาก | เผยแพร่แล้ว |
| QR code บนโปสเตอร์และสไลด์ | ลิงก์ตรงไป repository / ไฟล์ STL | Silpakorn KM Day 2569 |
| Silpakorn KM Day 2569 (Oral + Poster) | นำเสนอต่อคณะกรรมการ ผู้บริหาร และบุคลากร | 18 ธ.ค. 2569 |
| Light Survey Package (ด้านล่าง) | ชุดเริ่มต้นสำหรับส่วนงานที่ต้องการสำรวจแสงเอง | พร้อมใช้ |

## ทำซ้ำได้โดยไม่ต้องพึ่งผู้พัฒนา

- ทุกตัวเลขจากแบบจำลองในโปสเตอร์ สร้างใหม่ได้ด้วยคำสั่งเดียว (`make all` หรือดู README)
- การทดสอบ firmware รันบนคอมพิวเตอร์ได้โดยไม่ต้องมีฮาร์ดแวร์ (`tools/fw_sim/run.sh`)
- กล่องเป็นแบบ parametric ปรับขนาดตามโมดูลจริงได้ใน `hardware/enclosure/src/`

## บันทึกการถ่ายทอด

บันทึกเฉพาะกิจกรรมที่เกิดขึ้นจริง และเพิ่มแถวทุกครั้งที่มีการถ่ายทอด

| วันที่ | กิจกรรม | ผู้รับการถ่ายทอด / ส่วนงาน | หลักฐาน |
|---|---|---|---|
| 2569-10-23 | เปิด public repository พร้อมคู่มือ ไฟล์ STL และเครื่องมือ | บุคลากรมหาวิทยาลัยศิลปากร (เข้าถึงได้ทั่วไป) | commit history |
| 2569-12-18 | นำเสนอ Silpakorn KM Day 2569 (Oral Presentation + Poster) | คณะกรรมการ ผู้บริหาร คณาจารย์ บุคลากร | กำหนดการ / ภาพกิจกรรม |

## ขอรับการถ่ายทอดหรือร่วมพัฒนา

เปิด Issue หัวข้อ `[ขอรับการถ่ายทอด] ชื่อส่วนงาน` ระบุจำนวนห้องที่ต้องการสำรวจและช่วงเวลา
หรือส่ง Pull Request เพื่อเพิ่มบทเรียน แบบบันทึก หรือปรับปรุงเครื่องมือ
