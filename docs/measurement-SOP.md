# SOP การสำรวจความส่องสว่างในสำนักงานด้วย LightCheck KM

> เอกสารนี้เป็นแนวปฏิบัติการ **ตรวจคัดกรอง (pre-survey)** ใช้เพื่อหาจุดเสี่ยงให้ได้มากและเร็ว
> ผลที่จะใช้เป็นหลักฐาน Green Office ข้อ 5.2.1 ต้องวัดยืนยันด้วย **lux meter ที่ได้มาตรฐาน
> (CIE 1931 หรือ ISO/CIE 10527 หรือเทียบเท่า เช่น JIS) และมีใบสอบเทียบที่ยังไม่หมดอายุ** [1][3]

## 1. เกณฑ์ที่ใช้ตัดสิน

| ประเภทการวัด | เกณฑ์ | แหล่งอ้างอิง |
|---|---|---|
| พื้นที่ใช้ประโยชน์ในสำนักงาน (ห้องทำงาน ห้องประชุม ห้องคอมพิวเตอร์ ห้องอบรม) | ค่าเฉลี่ย ≥ 300 lux และจุดต่ำสุด ≥ 150 lux | [2] |
| งานประจำที่ใช้สายตา ณ จุดทำงาน (เขียน พิมพ์ บันทึกข้อมูล อ่าน) | 400–500 lux ที่ workstation | [2] |

- อย่าใช้ตัวเลขเดียวตัดสินทุกบริบท: 300/150 ใช้กับ **พื้นที่** ส่วน 400–500 ใช้กับ **จุดทำงาน**
- ค่าที่มากกว่า 500 lux ไม่ได้แปลว่า "ไม่ผ่าน" โดยอัตโนมัติ ให้ประเมินแสงจ้าและ glare เพิ่ม

## 2. ก่อนลงพื้นที่

1. ตรวจว่าเครื่องใช้ firmware v1.1.0 ขึ้นไป (หน้าจอตอนเปิดเครื่องแสดง `LightCheck v1.1`)
2. ตรวจโหมดบน LCD
   - `R` = Raw (ยังไม่ชดเชย)
   - `C` = ชดเชยแล้ว และอยู่ใน gain ที่สอบเทียบไว้
   - `!` = ชดเชยแล้ว แต่ gain ต่างจากตอนสอบเทียบ ให้วัดซ้ำหรือยืนยันด้วยเครื่องมาตรฐาน
3. สร้างผังห้องและจุดวัดด้วย `tools/survey/grid_planner.py` แล้วพิมพ์แบบบันทึกที่โปรแกรมสร้างให้
   ```bash
   python tools/survey/grid_planner.py --room R-201 --width 8 --length 6 \
          --desks "1.9,1.25;4.6,1.25" --out templates/R-201_survey.csv
   ```
   ตัวอย่าง: ห้อง 8 × 6 ม. ได้จุดกริด 4 × 3 = 12 จุด รวมกับจุดทำงานที่ระบุไว้
4. นัดช่วงเวลาให้เป็น **สภาพการทำงานปกติ และช่วงที่มีแสงธรรมชาติน้อยที่สุด** [3]

## 3. ขั้นตอนการวัด

1. บันทึกเวลา สถานะโคมไฟ ม่าน และแสงธรรมชาติลงแบบบันทึก
2. **การวัดพื้นที่**: วางหัวรับแสงในแนวระนาบสูง **75 ซม.** จากพื้น ที่จุดกึ่งกลางของแต่ละช่อง 2 × 2 ม.
   ถ้ามีขาตั้งกล้อง ให้ใช้ช่องน็อต 1/4" ใต้กล่องเพื่อตั้งความสูงให้คงที่และกันเงาผู้วัด [3]
3. **การวัดจุดทำงาน**: วางหัวรับแสง ณ จุดที่สายตาตกกระทบงานจริง เช่น ผิวโต๊ะ [3]
4. ถือเครื่องให้นิ่ง หัวรับแสงหงายขึ้น ผู้วัดยืนห่างและไม่บังแสง ไม่ใส่เสื้อสีขาวสะท้อนแสง
5. รอจน LCD แสดง `*` (ค่าเฉลี่ย 5 รอบนิ่ง CV < 2 %) แล้วจึงจดค่า บันทึก 3 ครั้งห่างกันเล็กน้อย
   ใต้โคม LED ค่าแต่ละรอบจะแกว่งจากการกระพริบ 100 Hz ของไฟกระแสสลับ อย่าจดค่าครั้งเดียว
6. บันทึก Raw Lux, Corrected Lux, gain, integration time, ห้อง/จุด, สภาพแสง, ผู้ตรวจ และหมายเหตุ

## 4. ตัดสินผลด้วย Guard band

ค่าจากเครื่องต้นแบบมีความคลาดเคลื่อน จุดที่อยู่ใกล้เกณฑ์จึงตัดสินด้วยเครื่องต้นแบบไม่ได้
ให้ใช้ช่วงกันชน (guard band) = ความคลาดเคลื่อนที่ระดับ 95 % (U95) จากรายงานสอบเทียบล่าสุด

| ค่า Corrected Lux | ผลการคัดกรอง | การดำเนินการ |
|---|---|---|
| ≥ เกณฑ์ × (1 + U95) | ผ่าน | บันทึกเป็น baseline |
| อยู่ในช่วง เกณฑ์ × (1 ± U95) | **ตรวจยืนยัน** | วัดซ้ำด้วยเครื่องมาตรฐานที่มีใบสอบเทียบ |
| < เกณฑ์ × (1 − U95) | ไม่ผ่าน | หาสาเหตุ ออกแผนแก้ไข แล้วยืนยันผลด้วยเครื่องมาตรฐาน |

ตัวอย่างจากผลจำลอง (U95 ≈ ±7.3 %): เกณฑ์ 300 lux จะได้ช่วงตรวจยืนยัน 278–322 lux
และเกณฑ์ 400 lux จะได้ช่วง 371–429 lux (ใช้ค่า U95 จากการสอบเทียบจริงเมื่อมีข้อมูล)

> หากยังไม่มีการสอบเทียบ (LCD แสดง `R`) ห้ามตัดสินผ่าน/ไม่ผ่านจากค่า Raw
> เพราะจากการประมาณด้วย datasheet ค่า Raw อาจต่ำกว่าจริงราว 25–50 % (ดู `calibration/`)

## 5. หลังวัด

1. จุดที่ไม่ผ่านหรือต้องยืนยัน ให้วัดซ้ำด้วยเครื่องมาตรฐานที่มีใบสอบเทียบ
2. ถ่ายภาพการวัดที่จุดทำงานและพื้นที่ทำงาน เก็บใน `evidence/` (ปิดบังใบหน้าและข้อมูลส่วนบุคคล) [1]
3. ออกแผนแก้ไขตามสาเหตุ เช่น ทำความสะอาดหรือเปลี่ยนโคมที่เสื่อม ปรับตำแหน่งโต๊ะ เพิ่ม task lighting
4. ตรวจซ้ำที่ตำแหน่งเดิมในสภาวะใกล้เคียงเดิม ถ้าการเปลี่ยนแปลงอาจกระทบระดับแสง
   ให้ตรวจวัดพื้นที่และบุคคลที่อาจได้รับผลกระทบเพิ่มเติมภายใน 90 วัน [3]
5. บันทึกบทเรียนใน `lessons-learned.md` และ commit ข้อมูลพร้อมเวอร์ชัน firmware และ calibration model
