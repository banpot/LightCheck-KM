# Troubleshooting

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| LCD ติดไฟแต่ไม่มีตัวอักษร | ความคมชัด (contrast) ต่ำ | หมุน trimpot สีฟ้าด้านหลัง backpack จนเห็นตัวอักษร |
| Serial เตือน `LCD not ACKing at 0x3F` | backpack เป็น PCF8574 (0x27) | แก้ `#define LCD_ADDR 0x27` แล้วอัปโหลดใหม่ หรือสแกน I2C เพื่อดู address จริง |
| `TSL2591 NOT FOUND @ 0x29` | สาย SDA/SCL สลับ ไฟ 3V3 หรือ GND หลุด | ตรวจตาม [wiring.md](wiring.md); SDA = D2, SCL = D1 |
| `Sensor read returned 0/0` | เซนเซอร์ถูกปิดทึบ หรือสายหลวม | เปิดหัวรับแสง ตรวจสายแล้วรีเซ็ต |
| v1.0 ขึ้น `Lux: SATURATED` สลับกับตัวเลข | bug auto-range ของ v1.0 แกว่ง gain | อัปเดตเป็น firmware **v1.1.0** (แก้แล้ว ดู CHANGELOG และ `tools/fw_sim`) |
| `Lux: SATURATED` ค้าง | แสงแดดตรงเกิน ~88,000 lux | ไม่ใช่การใช้งานในสำนักงาน ย้ายจุดวัดหรือบันทึกว่าเกินช่วง |
| LCD ขึ้น `!` หน้า Lux | ค่าที่อ่านใช้ gain ต่างจากตอนสอบเทียบ | วัดซ้ำเมื่อค่าคงที่ หรือยืนยันด้วยเครื่องมาตรฐาน (ปกติไม่ควรเกิดในช่วง 100–2,900 lux) |
| ค่าแกว่ง ไม่ขึ้น `*` | ไฟ LED กะพริบ 100 Hz / PWM dimming, เงาผู้วัด, มือสั่น | วางบนขาตั้ง (นอต 1/4") ยืนห่างหัวรับแสง รอ `*`; ถ้าโคมหรี่ไฟด้วย PWM ให้เปิดสว่างสุดขณะวัด |
| Raw Lux ต่ำกว่าเครื่องมาตรฐานมาก | ยังไม่ชดเชย (ปกติของ calculateLux) | สอบเทียบตาม `calibration/README.md` ห้ามใช้ Raw ตัดสินผ่าน/ไม่ผ่าน |
| ค่าเพี้ยนใกล้หน้าต่าง | แสงธรรมชาติมี IR สูง สเปกตรัมต่างจาก LED | วัดช่วงแสงธรรมชาติน้อยที่สุดตาม SOP และส่งยืนยันจุดนั้น |
| ESP8266 รีเซ็ตเองหรือ I2C ค้าง | pull-up 5 V จาก backpack / สายยาว | ดูหัวข้อ pull-up ใน [wiring.md](wiring.md) ใช้สายสั้นกว่า 20 ซม. |
| อัปโหลดไม่ได้ | ไม่มีไดรเวอร์ CH340 หรือเลือกพอร์ตผิด | ติดตั้งไดรเวอร์ CH340 และเลือกบอร์ด LOLIN(WEMOS) D1 R2 & mini |

ถ้ายังแก้ไม่ได้ เปิด Issue ใน repository พร้อมแนบ Serial log 20 บรรทัดแรก
และระบุเวอร์ชัน firmware กับรุ่นโมดูลที่ใช้
