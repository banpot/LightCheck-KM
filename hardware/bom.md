### น้ำหนักเส้นพลาสติกที่คาดว่าจะใช้

คำนวณด้วย [`hardware/enclosure/src/estimate_filament.py`](enclosure/src/estimate_filament.py)
โดยตัดไฟล์ STL เป็นชั้นละ 0.4 มม. ขอบ 1.2 มม. (3 walls) เป็นเนื้อตัน ผิวบน/ล่าง 0.8 มม. ตัน ที่เหลือ infill 20 %
ความหนาแน่น PLA+ 1.24 g/cm³

| ชิ้นส่วน | ปริมาตรตัน | ปริมาตรที่พิมพ์จริง (โดยประมาณ) | น้ำหนัก |

| Base | 32.2 cm³ | 29.7 cm³ (92 %) | 36.8 g |
| Lid | 13.2 cm³ | 11.9 cm³ (90 %) | 14.7 g |
| Skirt / purge | – | – | 2.0 g |
| **รวม** | | | **≈ 53.6 g → 53.6 × 0.48 ≈ 25.7 บาท** |
